# Проверяемые критерии приёмки

## Демонстрация / v0.1

- [x] Приватный GitHub repo.
- [x] Камеры/зоны и адаптивный интерфейс.
- [x] Синтетические видео с явным watermark и заранее заданными рамками.
- [x] Журнал и воспроизводимые видеофрагменты.
- [x] Подтверждение/отклонение оператором.
- [x] API authentication, provenance, event persistence и frame matching.
- [x] Ограничения frame/storage бюджета.
- [x] Ресурсный калькулятор и полная схема развёртывания.

## Один реальный источник

- [ ] Условия доступа и автоматической обработки подтверждены.
- [ ] HTTPS stream/JPEG доступен из выбранного облака.
- [ ] Проверены координаты, направление и зоны интереса.
- [ ] Подключена проверенная модель и подписанный/хешированный model manifest.
- [ ] Событие проходит от реального кадра до API без demo-флага.
- [ ] При закрытой вкладке сохраняется реальное событие и пригодный для просмотра клип.
- [ ] Установлены полнота pre/post и задержка на реальном источнике.

## Масштабирование

- [ ] Облачный аккаунт и реально доступная бесплатная мощность предоставлены.
- [ ] Измерения 1/5/10 потоков на выбранном оборудовании.
- [ ] 50 реальных камер с подтверждённым доступом; затем 100.
- [ ] Coverage по трём зонам соответствует фактическим подключённым камерам.
- [ ] 72-часовой soak test с сохранёнными метриками пропусков, CPU/RAM/IO/трафика и квот.
- [ ] Качество на отложенных эпизодах: event precision/recall, false alarms/camera-hour и detection delay.
- [ ] Проверка restart, отказа сети, диска, дефицита квоты и потери recorder.
- [ ] Бесплатность подтверждена настройками конкретного аккаунта; нет автоматического платного overage.

Ожидаемый frontend и целевой размер реестра не считаются выполнением реального этапа. Отдельно фиксируются snapshot mode и полноценный low-latency live video.
