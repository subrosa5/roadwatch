# Ресурсный план Iowa: решения и ограничения

Проверка источников и тарифов: 13.11.2026. Ограничения владельца: 0 ₽, без привязки карты, без его компьютера как производственного исполнителя, приватный репозиторий.

## Что реализуем сейчас

Два проверенных HLS-потока Iowa DOT → плеер hls.js на существующем приватном фронте. Видеосегменты браузер получает напрямую от владельца камеры. Наш Worker не ретранслирует гигабайты видео. Нативные контролы, ручное переподключение, сигнал отсутствия новых кадров через 20 секунд. Переключение камеры освобождает прежний HLS-плеер; опрос API не перезапускает текущий поток. Нет нарисованных детекций поверх неанализируемого видео.

Существующие D1/R2 сохраняют журнал и подтверждённые файлы событий. Смена региона не требует изменения схемы базы или прав доступа. Старые российские камеры исключены из активного реестра, исторические данные не удаляются.

## Воспроизводимый расчёт

Команда: `node tools/iowa-budget.mjs`. Тест: `tests/iowa.test.mjs`.

Основа — AVERAGE-BANDWIDTH двух успешно открытых плейлистов: 133995 и 262011 бит/с. Это заявленные средние битрейты источников в момент проверки, не длительный замер. Фактические значения и накладные расходы могут быть выше.

| Показатель | Результат | Что означает |
| --- | --- | --- |
| Суммарный битрейт | 0.396006 Мбит/с | Два потока одновременно |
| Входящее видео | 4.2768648 ГБ/сутки | Для облачного коллектора; фронт загружает только выбранную камеру |
| За 31 день | 132.5828088 ГБ | Без накладных расходов |
| Минутный кольцевой буфер | 2.970045 МБ | Только сжатые видеоданные двух камер; декодер и модель требуют дополнительной памяти |
| Один клип, 30 секунд | 0.502–0.983 МБ | По средним битрейтам отдельных камер |
| 5 клипов/сутки, 7 дней | 25.99 МБ в среднем; 34.39 МБ, если все со второй камеры | Без накладных расходов; это помещается в текущий предел приложения 100 МиБ, если нет других файлов |
| Анализ раз в 5 секунд | 34560 кадров/сутки | Две камеры; не исходная частота видеопотока |
| Предположение 50 мс/кадр | 14.88 CPU-часа за 31 день | Не измерено на модели; исключены декодирование, сеть и остальные расходы |
| Постоянный исполнитель | 744 машинных часа / 44640 минут | Считается даже тогда, когда модель ждёт следующий кадр |

Текущий API ограничен 500 наблюдениями/сутки. Отправка каждого результата анализа превышает предел в 69.12 раза. Нельзя просто повысить FPS коллектора: перед непрерывным запуском нужна агрегация на исполнителе — например, heartbeat раз в 15 минут и отправка только подтверждающих кадров инцидента. Сервер должен отдельно учитывать heartbeat и сырые наблюдения; текущая версия этого ещё не делает. Граница подтверждения события в 6 секунд сохраняется: два снимка с разницей в 15 минут не подтверждают одно событие.

## Конкретная граница готовности

Сейчас можно опубликовать и проверить воспроизведение двух дорожных камер, приватный журнал и работу уже существующего API сохранения событий. Нельзя честно объявить реализованными постоянное обнаружение ДТП/пожара и запись до события: в доступной инфраструктуре нет проверенного постоянного исполнителя и подключённых проверенных весов модели.

Оставшийся путь к постоянному CV: предоставить одному облачному процессу доступ к двум HLS, FFmpeg и проверенной ONNX-модели; измерить производительность на целевом CPU; включить heartbeat/агрегацию, кольцевой буфер, квоты клипов и фоновую очистку; проверить реальные фрагменты и ложные срабатывания днём/ночью. Существующий `collector/collector.py` уже содержит декодирование/буфер/двухкадровое подтверждение/отправку файлов, но сам код не выделяет ему облачный сервер и не создаёт веса.

Следующий внешний шаг — доступ к конкретному подходящему бесплатному облаку без карты или согласованный переход к редкой выборке. В каталоге интеграций найден Render, пока не установлен/не подключён. Его подключение позволит проверить реальный аккаунт и развернуть сервис, но само по себе не отменяет сон бесплатного инстанса. Ни платный тариф, ни публикация приватного репозитория, ни компьютер владельца для этого не активированы. Пока этот шаг не решён, сайт явно показывает «серверный CV не запущен».
