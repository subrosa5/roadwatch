# Осталось владельцу

14 ноября 2026. Репозиторий и консоль приватные. Постоянный исполнитель пока не создан; закрытие вкладки само по себе не запускает мониторинг.

1. Войти в [Botkeep](https://botkeep.cloud), выбрать бесплатный Python-профиль с 512 МиБ / 0.5 vCPU. Проверить нулевую цену и отсутствие требования карты. Если предложение изменилось, не подключать оплату.
2. Скачать архив из блока подключения в [консоли](https://roadwatch-moscow-console.dealreal259.chatgpt.site), импортировать ZIP. `main.py` и `requirements.txt` должны быть в корне. Выбрать Python 3.12, установку зависимостей и команду `python main.py`.
3. Первый запуск — `ROADWATCH_MODE=preflight` (по умолчанию). Он получает реальный кадр, проверяет модель и завершается. В JSON нужны `camera_network_test=true` и `resource_gate_passed=true`. Проверка GitHub не заменяет проверку самого Botkeep.
4. Через приватные Environment/Secrets хоста добавить существующие `INGEST_TOKEN` backend и `SITES_SERVICE_TOKEN` для приватного Sites. Не вставлять секреты в исходники, сообщения, ZIP или скриншоты. Runtime API URL уже заполнен. При ротации серверного ingest-секрета обновить его здесь; браузерную push-подписку затем пересоздать кнопкой.
5. Установить `ROADWATCH_MODE=run`, запустить процесс. В консоли у CBTV51 должен появиться свежий статус коллектора; во вкладке «Анализ» — JPEG с временем и результатом модели. Вторая камера пока резервная, без inference.
6. Закрыть вкладку на несколько минут, открыть снова: heartbeat должен остаться свежим. Пустой журнал без обнаруженных кандидатов нормален. Не создавать вымышленные реальные происшествия для проверки.
7. При необходимости нажать «Включить уведомления» и разрешить их в браузере. На поддерживаемом мобильном устройстве может потребоваться установка сайта на домашний экран. Реальную доставку при закрытом браузере нужно проверить на своём устройстве. Отказ разрешения не мешает просмотру журнала.

Полная инструкция пакета: [collector/botkeep/README.md](../collector/botkeep/README.md). Совместимость профиля, долговременная работа и фактическое качество модели на этом ракурсе подтверждаются после запуска. Бесплатный beta-host не предоставляет обещания непрерывной доступности; при исчерпании квот система останавливает публикацию и показывает состояние.

В production готовится только кандидат огонь/дым для проверки человеком. Исследовательский модуль ДТП не подключён к журналу: для стационарной камеры нужна отдельная валидация и, вероятно, обучение.
