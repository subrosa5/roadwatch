# Международные камеры: проверка источников

Проверено 13 ноября 2026, около 11:55–12:00 UTC. По просьбе владельца российское направление больше не развиваем. Этот отчёт выбирает новый источник; производственная конфигурация камер и интерфейс пока не перенесены.

## Решение

Первый кандидат — США, Iowa DOT. Начать с двух проверенных камер, затем подобрать третью резервную. Не включать сотни камер только потому, что их адреса есть в каталоге.

Официальная документация: https://iowadot.gov/travel-tools/iowa-511/511-data-feeds

Публичный каталог ArcGIS: https://www.arcgis.com/home/item.html?id=c4063f200a7b4da5826e2ac86c677cf5

Адрес FeatureServer берётся из опубликованных метаданных этого каталога. Слой 0 поддерживает обычный публичный query. На момент проверки получено 1261 записей, из них 699 с непустым VideoURL. Это число записей, а не количество проверенных работающих видеопотоков. Без регистрации, ключа или банковской карты.

Получены короткие fMP4-сегменты, объединены с init, воспроизведены в тестовом браузере; проверены размеры видео и состояние декодера. Продолжительность MP4, собранного из одного сегмента без перемещения временной шкалы, не является продолжительностью записи: исходные fMP4 сохраняют временные отметки трансляции.

Нужен HLS-плеер с поддержкой MSE для Chromium/Firefox и native HLS там, где браузер его поддерживает. Простая замена iframe на video src=m3u8 не обеспечивает поддержку во всех браузерах. Адреса брать из каталога: DOT сообщил о миграции системы в 2026 году, поэтому не конструировать домены и пути самостоятельно.

## Следующая реализация

1. Перенести названия, зоны, карту и часовые пояса фронта с Москвы на Iowa; действующий URL сайта можно сохранить, смена домена не нужна для воспроизведения.
2. Подключить HLS двух проверенных камер, выводить ошибку и время последнего реально декодированного кадра. Тестировать именно на опубликованном фронте. Не называть работающим CV простое воспроизведение видео.
3. Переоткрывать каталог при изменении адресов; не проксировать постоянно весь видеотрафик через бесплатный Worker, если браузер может получать поток напрямую.
4. Отдельно проверить условия автоматизированного анализа, записи и публикации клипов. Метаданные ArcGIS обозначены CC BY 4.0 с дополнительными условиями Iowa DOT; это само по себе не доказывает идентичные права на каждую видеозапись. Использовать атрибуцию Iowa DOT и ссылку на источник.
5. Для фонового CV нужен отдельный облачный исполнитель с декодированием видео и проверенной моделью. Бесплатность источника не создаёт бесплатный непрерывный вычислитель. Предыдущие ограничения по отсутствию карты и пользовательского компьютера сохраняются.
6. Запись до события возможна только при работающем кольцевом буфере на исполнителе. Закрытый браузер не должен останавливать фоновый анализ, поэтому браузерный CV не заменяет этот исполнитель.

Оценка нижнего порядка: при 0.15–0.30 Мбит/с одна непрерывная трансляция передаёт около 1.6–3.2 ГБ/сутки; две — 3.2–6.5 ГБ/сутки. Это оценка из битрейта, без накладных расходов и хранения. Постоянное хранение и 24/7 CV не объявлены реализованными. Никакие новые платные аккаунты, ключи или обходы ограничений доступа при исследовании не использованы.
