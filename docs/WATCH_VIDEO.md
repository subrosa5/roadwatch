# Непрерывное видео и рамки

Коллектор v4 передаёт закрытые MPEG-TS сегменты из существующего кольцевого буфера FFmpeg. Видеодорожка копируется (`-c:v copy`), поэтому частота просмотра не ограничена 2–4 кадрами/с, выбранными для анализа. Нейросеть по-прежнему работает только на облачном коллекторе.

JPEG для анализа получает имя с FFmpeg PTS. Результат содержит `media_time` в той же шкале, что и начало/конец сегмента в `segments.csv`. Плеер использует HLS Program Date Time для определения положения внутри видео. Эта шкала служит синхронизации и **не является подтверждённым временем съёмки камеры**. [API hls.js `playingDate`](https://hlsjs.video-dev.org/api-docs/hls.js.hls.playingdate).

Между двумя измерениями одного ID координаты рамки линейно интерполируются, если разрыв не превышает 1,1 секунды. Новые ID не появляются раньше первого измерения; потерянные объекты не продолжают движение бесконечно. Без часов плеера, при старом релейном потоке или большом разрыве рамки скрываются. Изображения не генерируются и не интерполируются.

Передача запускается только при открытом просмотре транспорта. Хранятся шесть последних видеосегментов, каждый не больше 600 КБ; квота передачи — 200 МиБ/сутки. После прекращения передачи последние сегменты удаляет фоновая очистка в течение суток. Оригинальная HLS-задержка, закрытие сегмента, сеть и буфер плеера остаются; нулевая задержка не обещается.

Если коллектор v4 не подключён или релей устарел более чем на 20 секунд, интерфейс переходит на прямое видео Iowa DOT с явной надписью, что трекинг не поступает. Вчерашний кадр не подменяет видео. После 45 секунд без новых файлов FFmpeg коллектор перезапускает подключение к источнику.

Проверка транспорта на локальном синтетическом ролике: коллектор → закрытый Worker API → TS → настоящий браузер; видео продвинулось на 5,007 секунды, декодирован 61 кадр за 5 секунд, синхронизированные рамки отображались, необработанных ошибок JavaScript не было. Это проверка механизма, а не точности модели или производительности Hostrix. Рабочая проверка требует установки архива v4 на Hostrix.
