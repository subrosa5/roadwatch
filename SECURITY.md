# Границы безопасности

Это private R&D prototype, без независимого security review. Использовать только источники с подтверждённым доступом и условиями обработки. Проект не содержит обхода доступа, обнаружения открытых админок, распознавания личности или автомобильных номеров.

API закрыт bearer tokens; роли viewer/operator и collector разделены. Значения 32+ символа, раздельные, не встроены в исходники. Viewer может читать все события и менять review; персональных ACL/SSO нет. TLS/reverse proxy и backup должен обеспечить владелец облачного runtime. Privacy приватного Sites frontend не распространяется автоматически на другой API.

Наблюдения — недоверенные данные. Проверяются schema, label, координаты boxes, freshness, порядок и источник. Это не подтверждает, что скомпрометированный collector/model не подделал событие. SHA-256 evidence защищает сверку сохранённых байтов; подпись камеры, доверенное время и forensic chain of custody отсутствуют.

Rate/body/frame/evidence budgets ограничивают ущерб, но не являются универсальным ограничителем расходов облака. Полный диск, FFmpeg process exhaustion, reverse-proxy concurrency и billable storage требуют отдельных лимитов. В проекте нет автоматического перехода на платные тарифы и нет обещания SLA.

Секреты камеры и токены сообщать защищённым каналом владельцу проекта. Не создавать публичные issues с видеозаписями, адресами приватных потоков, содержимым .env или данными посторонних людей. Подтверждённый инцидент в интерфейсе означает решение оператора, а не юридически установленный факт.
