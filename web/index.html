Облачный коллектор · Hostrix

Активность коллектора не подтверждена.

  1. Остановить существующий сервер Hostrix кнопкой Stop.
  2. Скачать актуальный пакет Hostrix ZIP, загрузить через Files → Upload files и распаковать Unzip с заменой. Не использовать Redeploy: установленные пакеты и данные нужны для продолжения работы.
  3. Оставить команду python3 -u hostrix_bootstrap.py --repair, Python 3.12 и ROADWATCH_MODE=run. Автоустановка «Install packages first» выключена. Существующие ключи менять не нужно.
  4. Нажать Start, дождаться preflight и проверить статус здесь. Новый профиль — 4 кадра/с; источник и сеть добавляют задержку.

Облачное сопровождение транспорта: требуется запуск коллектора.
